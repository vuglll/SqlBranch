# Tasks

Every Docker test in every group is an integration test tagged so it runs only when `SQLBRANCH_IT=1`. "Regenerate the agent skill" means `dotnet run --project src/SqlBranch.Cli -- skill export --dir skills/sqlbranch --force` and committing `skills/sqlbranch/`; the unit suite's comparison must pass. Until task 4.2 exists, tests that need a format-2 pool get one from a test helper that writes the format-2 layout (D2, D3, D5) directly, including an unfinished upgrade (state `running`) and legacy items in the format-1 layout; after 4.2 the integration tests also build one with `pool upgrade --yes`. F4 extends the same helper to write later versions under `versions/<id>/`.
