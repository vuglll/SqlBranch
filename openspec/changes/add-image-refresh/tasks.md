# Tasks

Every Docker test in every group is an integration test tagged so it runs only when `SQLBRANCH_IT=1`. "Regenerate the agent skill" means `dotnet run --project src/SqlBranch.Cli -- skill export --dir skills/sqlbranch --force` and committing `skills/sqlbranch/`; the unit suite's comparison must pass.

## 1. Verify platform assumptions

This group runs first after approval, on the maintainer's Linux machine, where Docker is available. Record environment, date, observed results and source links in `docs/research/2026-11-19-image-refresh-facts.md`. A failed spike means revising design.md before relying on the fact.

- [ ] 1.1 Measure free bytes before and after staging, restore, masking, sealing, publish and prune on a thin and a copy pool with one retained version, for a local backup, a URL backup and a script that grows the database. Inject exhaustion before staging, before restore and during growth. Verify: old version checksums unchanged, branch reads succeed, exit 1 with `pool_full` naming measured free and known required bytes, and the phase table is in the research note.
- [ ] 1.2 Time a fixed read/write workload alone and while a restore and masking script run, with a barrier inside masking to test reads, commits and an independent create before publication. Verify: zero lost writes and zero dropped sessions; throughput and p50/p95 latency for both runs, engine and pool are in the research note.
- [ ] 1.3 On directory and loop-xfs pools, one of them in copy mode, kill the writer and restart the engine on both sides of the catalog rename, each flush, the credentials-file rename, and a prune unlink. Verify: exactly one complete current version, session locks of dead clients released, leftovers visible to a status probe, a retry succeeds, surviving branches keep their rows, and the credentials file is always the complete old or new content. The crash matrix is in the research note.
- [ ] 1.4 Run a stub job (success, then a masking failure) under cron and a scheduled CI job on Linux, and under launchd and Windows Task Scheduler where a machine is available. Verify for each: working directory, tool discovery, secret injection, exit propagation, and that argv and logs hold no sentinel secret. Record each verified invocation. Record launchd and Task Scheduler as "not verified" when no machine was available; their examples then ship with that mark (task 5.8).
